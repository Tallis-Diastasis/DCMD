# DCMD
Discord Piper to arch or something.

## Running
```
git clone https://Tallis-Diastasis/DCMD.git
cd DCMD
pip install -r requirements.txt
```
Create a .env file:
```
TOKEN="<Your bot token>"
CHANNEL_ID=
```
And finally
```
python main.py
```

## Warning
Please use this on a virtual machine. Don't let other people run random commands on your machine. And most importantly, stay safe - by using this in a Discord server you are giving access to your internet and IP address. Beware.
